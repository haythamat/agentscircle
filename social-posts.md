## LinkedIn (English)

I built AgentsCircle, a desktop app that puts all the AI coding agents you use on a project into one shared chat.

Instead of switching between Claude Code, Codex, Cursor and others, and re-pasting context each time, you @mention any agent in one thread tied to your project folder. Each agent sees the same conversation and project state, and you can hand work from one agent to another.

What's in it today:
- One thread per project folder, with @mentions for each agent and account
- Hand-offs between agents, with the full task text shown
- A Files tab with previews, diffs and per-agent commits
- Edit a file by asking an agent in plain language, or pick an element in an HTML preview and say what to change
- Bring in a conversation from a Claude or Codex share link

It runs as a desktop app for macOS and Windows.

I'm looking for developers to try it on a real project and tell me what breaks or what's missing. Download it from agentscircle.dev, and check the public roadmap there for what's coming next, including Pro and Teams.
